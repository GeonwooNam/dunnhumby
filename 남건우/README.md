# 남건우 — 이탈 조기 탐지 분석

이탈 정의 → 사전 징후 확인 → 조기 탐지 규칙 백테스트 순서의 분석.

```
code/
  00_공통/            베이스 레이어 정제 (DuckDB)
  01_가설검증/         q01~q07: RFM 세그먼트, 캠페인 전후, 쿠폰, 이탈 정의, 방문간격, DiD, RFM 안정성
  02_세그먼트_이탈징후/  가구 2×2 세그먼트, 이탈 사전징후(70%/70일), 캠페인 효과 착시(세그먼트 분해)
  03_조기탐지_백테스트/  "간격 ×2 경보" 규칙 홀드아웃 백테스트, 지출 감소 선행신호, 리드타임 검증
reports/   위 코드별 결과 정리 (같은 번호 체계)
outputs/   실행 결과 원문 (csv·txt·png)
docs/      전처리 기준·지표 정의
```

재현: `pip install duckdb pandas matplotlib`, 원본 CSV 8개를 `data/raw/`에 두고 `code/00_공통/build_base_layer.py`부터 순서대로 실행.

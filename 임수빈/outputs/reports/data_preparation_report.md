# Project 2 데이터 준비 결과

## 처리 범위

- 원본 위치: 로컬 원본 데이터 폴더(저장소에서 제외)
- 원본 파일은 수정하지 않음
- 거래 데이터 2,595,732행과 프로모션 노출 데이터 36,786,524행을 포함한 CSV 8개 점검
- 고객-주차, 고객 특성, 구매 간격, 프로모션 주차 요약 테이블 생성

## 데이터 품질 핵심 결과

- 거래-상품 조인 성공률: 100%
- 캠페인 대상 가구-거래 고객 조인 성공률: 100%
- 캠페인 배정-캠페인 설명 조인 성공률: 100%
- 쿠폰 상품-상품 마스터 조인 성공률: 100%
- 쿠폰 사용-쿠폰 발급 정보 조인 성공률: 100%
- 인구통계는 전체 2,500가구 중 801가구(32.04%)만 제공됨. 결측치가 아니라 데이터 제공 범위의 제한이므로 인구통계를 필수 조건으로 걸면 표본이 크게 줄어듦.
- `coupon.csv`에는 완전히 동일한 행이 5,164개 있음. 쿠폰 분석 전에 중복 제거가 필요함.
- 거래 데이터에는 음수 매출은 없으나 매출 0인 행 18,850개, 수량이 0 이하인 행 14,466개가 있음. 이를 즉시 삭제하지 말고 반품·조정·증정 레코드 여부를 먼저 확인해야 함.
- 마지막 캠페인 24번은 종료일이 DAY 719이지만 거래 데이터는 DAY 711에서 끝남. 이 캠페인은 완전한 사후 성과 측정에서 제외하거나 관측 중단을 명시해야 함.

## 이탈 분석용 스냅샷

- 전체 관측 종료일: DAY 711
- 특성 산출 기준일: DAY 655
- 검증 구간: 이후 56일
- 기준일까지 거래 이력이 있는 고객: 2,499가구
- 이후 56일간 재구매가 없는 고객: 284가구(11.36%)
- 개인별 중앙 구매 간격의 1.5배 이상 지연되고 최소 14일이 지난 규칙:
  - 위험 고객 647가구
  - 실제 이탈 포착률(Recall) 61.97%
  - 위험 고객 중 실제 이탈 비율(Precision) 27.20%

현재 규칙은 최종 정의가 아니라 비교 기준선이다. 위험 비율을 3배 이상으로 강화하면 정밀도는 약 32.1%로 높아지지만 재현율은 50.0%로 낮아진다. 다음 분석에서는 고객가치와 함께 임계값별 비용-효과를 비교해야 한다.

- `data/processed/file_profile.csv`: 파일별 행·열·결측·중복 요약
- `data/processed/join_quality.csv`: 주요 테이블 조인 성공률
- `data/processed/customer_week.csv`: 고객×주차 분석 테이블
- `data/processed/customer_features.csv`: 기준일 이전 고객 행동 특성과 56일 이탈 라벨
- `data/processed/purchase_intervals.csv`: 고객별 구매일 간격

# Dunnhumby — 이탈 방지 및 마케팅 효율 최적화 분석

YBIGTA DA 26-2 Project 2. Dunnhumby "The Complete Journey" 데이터로 고객 이탈·마케팅·매장 프로모션을 분석하고 전략을 도출.

## 폴더 구조

```
submission/
├─ code/
│  ├─ python/        # pandas 기반 EDA·분석 스크립트
│  └─ queries/       # DuckDB(SQL) 분석 — 역할별 정리
│     ├─ 00_공통/           # 전처리 기준 (모든 분석의 출발점)
│     ├─ 01_이탈분석/       # 방문간격·이탈정의(홀드아웃)
│     ├─ 02_고객세그먼트/   # 위험군 가치·세분화·최종타겟
│     ├─ 03_마케팅_쿠폰/    # 셀렉션바이어스·수신율·최근선호·증분매출
│     └─ 04_매장_프로모션/  # 교차구매·연관카테고리·카테고리연결
└─ output/
   ├─ charts/        # 차트 (png)
   ├─ tables/        # 집계 결과 테이블 (csv, parquet)
   └─ logs/          # 스크립트 출력 원시 수치 (txt)
```

## 최종 전략 (요약)

일괄 마케팅은 효과 근거가 없고, 맥락(개인 선호·상품 묶음·타이밍)에 맞출 때만 신호가 난다.
쿠폰(개인 레버)과 진열(매장 레버)은 개입 대상이 달라 **나눠 층으로 쌓는다.**

- **전략 A (쿠폰)**: 뜸해지는 고가치 감지(간격 1.5배 → 카테고리 다양성 70%↓) → 최근 선호 카테고리 맞춤 발송
- **전략 B (진열)**: 검증 카테고리(BACON·LUNCHMEAT·DINNER SAUSAGE)를 연관 상품과 묶음(zone) 진열
- **확대는 매출이 아니라 증분이익으로 판단**, 감지 위에 A/B 실험으로 효과 측정

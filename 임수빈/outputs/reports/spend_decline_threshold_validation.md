# 지출 감소 탐지 임계값 선택 및 홀드아웃 검증

## 판정

> 선택 규칙의 성능이 미사용 검증 구간에서 충분히 재현되지 않았다.

## 검증 원칙

- 개발 시점: W50, W58, W66, W74
- 최종 검증 시점: W82, W90
- 개발 구간에서만 임계값을 선택하고 검증 구간에는 선택된 규칙을 한 번만 적용했다.
- 후보 조건: 개발 경보 30건 이상, precision 50% 이상
- 선택 기준: 조건을 통과한 후보 중 F1 최대, 동률이면 감소 매출 포착률 우선

## 선택된 규칙

- 카테고리 다양성 비율: 85% 미만
- 방문 간격 조건: 사용하지 않음
- 개발 Precision: 51.5%
- 개발 Recall: 50.5%
- 개발 F1: 0.510
- 개발 감소 매출 포착률: 54.2%

## 미사용 검증 구간 결과

- 고객-시점 관측치: 726
- 경보: 185
- 실제 30% 이상 감소: 153
- Precision: 45.4% (cluster bootstrap 95% CI 37.5%-53.1%)
- Recall: 54.9% (95% CI 46.8%-62.7%)
- 기준 감소율: 21.1%
- Precision lift: 2.15배
- 감소 매출 포착률: 61.5% (95% CI 53.3%-69.2%)
- 경보 1건당 포착된 감소 매출: 225.38

## 기존 70% 규칙과 비교

- 기존 다양성 70% 규칙 검증 Precision: 62.2%
- 기존 다양성 70% 규칙 검증 Recall: 36.6%
- 기존 다양성 70% 규칙 검증 Lift: 2.95배
- 기존 다양성 70% 규칙 검증 감소 매출 포착률: 44.7%
- 85% 규칙은 더 많이 포착하지만 사전 precision 기준을 통과하지 못했다. 따라서 70%는 개입 후보, 85%는 저비용 관찰 후보로 구분하는 것이 안전하다.

## 해석

- 임계값 선택은 개발 시점에만 의존했으므로 검증 성능이 실제 일반화 가능성에 대한 핵심 근거다.
- 같은 고객이 두 검증 시점에 포함될 수 있어 신뢰구간은 고객 단위 군집 부트스트랩으로 계산했다.
- 경보 비용과 실제 방어 가능한 매출 비율은 데이터에 없으므로, 경보 1건당 포착 감소 매출은 개입 손익의 상한 참고치다.
